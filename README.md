# 🌸 She Can Foundation – NGO Website

A responsive and modern NGO website built using **HTML, CSS, and JavaScript**. This project showcases the mission of *She Can Foundation*, which focuses on empowering women through education, healthcare support, skill development, and community-driven programs.

---

## 🌐 Live Demo
👉(https://github.com/Vibha2885/She-can-foundation)

---

## 📌 Project Overview

This website is designed as a professional landing page for an NGO. It presents the foundation’s mission, impact, and programs in a clean and engaging way. The UI is fully responsive and includes smooth animations and interactive elements to enhance user experience.

---

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Modern and clean UI layout
- Fixed navigation bar with scroll effect
- Animated statistics counter (impact numbers)
- Testimonials section with real stories
- About and vision sections
- Call-to-action for volunteering
- Smooth scrolling and transitions

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox, Grid, Animations)  
- JavaScript (DOM Manipulation, Intersection Observer API)
